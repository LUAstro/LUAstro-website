LUAstro - JWST Data Processing Workshop

This email was created with the campaign name: JWST Data Processing

This email was created with the purpose: JWST Data Processing (this is usually left blank)

This email was sent on the 21/01/2025 to all 173 LUAstro members at the time .

Hello Astronomers!

Tomorrow (22/01/25) at 7pm we're going to be demonstrating how we can use similar techniques to last week to process professional data from JWST. This data has been precalibrated, so there's no need for any pre-processing. The JWST data can also be processed using GIMP, available on computers in the Astrolab, so, contrary to the poster, laptops are NOT required this time (but would be preferable).
If you missed last week, we will be re-running that workshop simultaneously, in which case a laptop would be necessary.

We hope to see you there!

- LUAstro
